Human-Like Interaction
======================

Design how ChatbotLab bots communicate: their tone, pacing, and timing.
These features shape the realism of each conversation and make interactions
feel more natural to participants.

Typical setup includes designing the bot's prompt and configuring behavioral
parameters that control delay, typing speed, and message chunking.

Topics Covered
--------------

- **Conversation Design:** Crafting initial prompts and starting messages  
- **Behavioral Parameters:** Reading/writing speed, jitter, context window
